Colt Query Language Specification

Colt is the declarative, multi-model query language for ColtaneDB. It provides a clean, single-language abstraction across relational tables, document projections, vectors, and key-value stores without vendor lock-in.

-- Basic Colt statement DEFINE COLLECTION users STRICT @backend(neon) { id: uuid @key, email: text @unique, created: time @default(now) }

Collections & Schemas

Collections define named datasets. The STRICT modifier enforces explicit field definition and schema validation. Each collection must declare exactly one primary backend using the @backend(provider) annotation.

DEFINE COLLECTION articles STRICT @backend(neon) { id: uuid @key, slug: text @unique, body: text, metadata: doc }

Data Types

Colt includes normative Tier-1 data types mapped to optimal native representation in PostgreSQL:

  • uuid — 128-bit universally unique identifiers.
  • text — Variable length string literals.
  • int — 64-bit integer values.
  • float — Double precision floating point numbers.
  • bool — Two-valued boolean logic (true / false).
  • time — Timestamp with timezone (timestamptz).
  • doc — JSON/JSONB structured documents with nested path access.
  • vector(dimension) — Dense vector embeddings for cosine/euclidean similarity with @index(hnsw).
  • link<Target> — Batched foreign record relationships.
  • list<Type> — Homogeneous typed arrays.

Annotations

Annotations begin with @ and enrich collections or fields with execution and storage metadata:

@key -- Primary key constraint (exactly one per collection) @unique -- Unique constraint index @default(now) -- Statement-time default value @index(hnsw) -- Vector index for fast approximate nearest neighbor search @backend(neon) -- Specifies the primary storage engine

Querying with FIND

Queries retrieve records with field selection, compound filters (WHERE), ordering (ORDER BY), and pagination (LIMIT / OFFSET):

FIND books SELECT title, author, metadata.edition WHERE views > 10 AND published != null ORDER BY views DESC LIMIT 20 OFFSET 0

Mutations (CREATE, PUT, DELETE)

Colt provides explicit record creation, whole-record replacement (PUT), and targeted deletions:

-- Insert with auto-generated or specified fields CREATE books { title: "Dune", views: 100 } -- Whole-record update with ON CONFLICT resolution PUT books:11111111-1111-4111-8111-111111111111 { title: "Dune Messiah", views: 120 } -- Conditional deletion (constant true is rejected) DELETE books WHERE views == 0

Transactions (ATOMIC)

The compiler can plan supported single-primary ATOMIC blocks. This preview does not execute transactions.

ATOMIC { DELETE books:33333333-3333-4333-8333-833333333333; PUT authors:22222222-2222-4222-8222-222222222222 { name: "Frank Herbert" } }

Diagnostics Codes Reference

The compiler reports strict diagnostics formatted as COLT####:

COLT1001 -- Unexpected character COLT1003 -- Malformed numeric literal COLT1005 -- Unterminated string literal COLT1006 -- Unterminated block comment COLT2001 -- Unsupported backend target (M1 supports @backend(neon) and @backend(supabase)) COLT2002 -- Unknown collection reference COLT2004 -- Unknown field in projection or filter COLT2005 -- Constant-true collection delete rejected (safety gate) COLT2006 -- Duplicate collection definition COLT2007 -- Duplicate field definition COLT2010 -- Vector dimensions must be a positive integer COLT2014 -- Missing required non-nullable field COLT2016 -- Cross-backend ATOMIC transaction blocked

Python SDK preview

The Python package is in this repository and is not published to PyPI yet. Install it from a local checkout:

python -m pip install -e ./python

Run Colt scripts directly from Python:

import coltane client = coltane.Client("http://localhost:3000") # Plan and compile any Colt script plan = client.plan(""" FIND books SELECT title, views WHERE views > 10 ORDER BY views DESC LIMIT 10 """) for step in plan.steps: print(f"Backend: {step.backend} | Operation: {step.operation}") print(f"SQL: {step.parameterized_statement}") print(f"Parameters: {step.params}")

Fluent Python query builder:

from coltane import query, collection # Define schema schema = ( collection("products", backend="neon") .field("id", "uuid", "@key") .field("title", "text") .field("price", "float") ) print(schema.to_colt()) # Build query q = query("products").select("title", "price").where("price < 50.0").limit(20) print(q.to_colt())
